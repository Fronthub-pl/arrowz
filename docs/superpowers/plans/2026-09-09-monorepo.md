# Monorepo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the repository into a monorepo with the engine and the CLI as
two Deno workspace packages, a pnpm workspace with Nx on top, a Node build of
the engine, editor settings, CI and updated documentation, with every board
still bit-identical.

**Architecture:** Two runtimes, each in its role. `packages/engine`
(`@arrowz/engine`) and `packages/cli` (`@arrowz/cli`) are Deno workspace
members tested by `deno test`; Nx orchestrates them through `run-commands`
targets and will later orchestrate the Node applications. The engine also
carries a `package.json` and is emitted to `dist/` by `tsc` with
`rewriteRelativeImportExtensions`, so Node consumers link it with
`workspace:*` and get the same boards (proved by a Node smoke test over the
golden fingerprints).

**Tech Stack:** Deno 2.9.6, pnpm 12.3.4 (through corepack), Node 24, Nx
23.2.x, TypeScript 5.9.x (emit only), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-09-monorepo-design.md`

## Global Constraints

- Everything in the repository is in English (code, comments, docs, commits, branch names). Conversation with the user is in Polish.
- `main` changes only through a pull request; work on branch `feat/monorepo`, created from `main` once PR #25 (this plan) is merged.
- Commit messages: imperative, English, no attribution lines.
- Boards must stay bit-identical: `fingerprints.test.ts` (nine golden boards) must pass unchanged after every task, and the Node smoke test must reproduce the same fingerprints from `dist/`.
- Engine strictness stays: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`; lint forbids `any` and non-null assertions; no value-changing fallback in the engine.
- `neutral.test.ts` keeps its list of runtime-neutral modules and its forbidden patterns; it must not be weakened.
- Deno-side quick check: `deno task verify` at the root. Whole repository: `pnpm nx run-many -t verify`.
- The canonical CLI prefix stays `deno task carve`, run from the repository root.
- Versions: `packageManager` `pnpm@12.3.4`; `nx` `^23.2.0`; `typescript` `^5.9.3`; Node 24; Deno `~2.9`.
- Board store default moves to `packages/cli/boards/` (gitignored), still overridable with `ARROWZ_BOARDS_DIR`.
- In background shells call GitHub CLI by path: `/opt/homebrew/bin/gh` (the alias goes through 1Password and needs a terminal).

```sh
SRV=$!
```

```js
// Proves that the tsc emission in dist/ is the same engine: every golden
// board of fingerprints.json except big500 (21 771 pieces, left to the Deno
// test) must reproduce its fingerprint under Node.
import { readFileSync } from 'node:fs'
import process from 'node:process'
import { defaultParams, fingerprint, generate } from '../dist/mod.js'
import { parseArgs, parseSimpleArgs } from '../dist/command.js'
import { simpleParams } from '../dist/lab-simple.js'

const golden = JSON.parse(readFileSync(new URL('../fingerprints.json', import.meta.url), 'utf8'))

function paramsOf(c) {
  if (c.argv === null) return { ...defaultParams(), W: 40, H: 40, seed: 1, voidFrac: 0.1 }
  if (c.argv.includes('--advanced')) {
    return parseArgs(c.argv.filter((a) => a !== '--advanced' && a !== '--dry-run')).params
  }
  return simpleParams(parseSimpleArgs(c.argv).choice)
}

let failures = 0
for (const c of golden.cases) {
  if (c.name === 'big500') continue
  const r = generate(paramsOf(c), { unchecked: c.argv === null })
  const got = fingerprint(r.board)
  const ok = got === c.fingerprint && r.board.pieces.length === c.pieces
  console.log(`${ok ? 'ok  ' : 'FAIL'} ${c.name} ${got} (${r.board.pieces.length} pieces)`)
  if (!ok) failures++
}
if (failures > 0) {
  console.error(`${failures} golden board(s) differ under Node`)
  process.exit(1)
}
console.log('all golden boards reproduce under Node')
```
